## Requisitos

* Unity **6000.0.58f2**
* Render Pipeline: Universal Render Pipeline (URP)
* Paquetes: Visual Effect Graph, Shader Graph
* Assets de terceros incluidos (no redistribuibles): AmplifyShaderEditor, QuickOutline

## Uso

1. Clona el repositorio y añádelo en Unity Hub (*Add project from disk*).
2. Ábrelo con Unity **6000.0.58f2**.
3. Abre la escena `Assets/3-Scenes/Main.unity` y pulsa **Play**.
